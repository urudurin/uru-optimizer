# Data sources for the ZZZ and WuWa modules

**Personal, non-commercial use only.** The game data and recommendations used by `src/lib/games/` come from the games
themselves, community datamines, community wikis and the user's own screenshots and exports. None of it may be used to
make money: no paid features, ads, subscriptions or resale built on this data. Game names, data and art belong to their
publishers (HoYoverse for Zenless Zone Zero, Kuro Games for Wuthering Waves). This project isn't affiliated with them or
with any of the sites below.

Every value in the code carries a confidence tag: `confirmed` (matched the in-game stat screen), `sourced` (from one of
the sources below) or `unverified`.

## Images (ZZZ)

Agent art and icons, W-Engine art and disc set icons are loaded from Enka.Network when a page is viewed. Enka's ZZZ store files name them (Enka's API docs, "Icons and Images") and enka.network serves them to other sites. Nothing is copied into this repo (`zzz/data/images.ts`). The art belongs to HoYoverse; personal, non-commercial use. Not used: Fandom wikis (their Terms of Use forbid scraping and automated access).

Character icons and wish splash art, weapon icons and artifact piece icons are loaded from Enka.Network when the Characters page is viewed. Enka's Genshin store files (avatars SideIconName, weapons Icon, relics Items Icon) name them and enka.network serves them as /ui/<name>.png (Enka's API docs, "Icons and Images"). Nothing is copied into this repo (`genshin/data/images.ts`). The art belongs to HoYoverse; personal, non-commercial use.

Wuthering Waves has no image source the site can fetch: Enka doesn't cover it, the datamine tables are text only, and Fandom's Terms of Use forbid automated access. The user can save art by hand into `wuwa/user-art/`, which is gitignored (only its README is committed); pages show initials for anyone without a file there. The art belongs to Kuro Games; personal use.

WuWa echo score weights (`wuwa/data/statPriorities.ts`): our own table from in-game skill descriptions, edited by hand, never copied from third-party guide sites; unverified entries need review. Entries marked 'guide' (Suoming, Hsin, Shorekeeper, Phoebe, Yuanwu, Chixia, Aalto, Jianxin, Roccia, Yangyang, Youhu and the three Rovers) follow the substat priority on Kuro's own guide site (wuwaguide.kurogames.com), read by hand one page at a time; each cites its guide by role_id and contributor (Void Enigma, Krow, WW Echoes). The WuWa build rating's 100% is our own standard build modelled on KQM Standards (`wuwa/stats/echoScore.ts`): there is no community standard for WuWa.

## Imported presets (any game)

Users can import a presets file of their own, for example notes taken from a guide site such as Prydwen or a community
group such as SipSip Squad. That file stays in the user's browser (`<game>-imported-presets` in local storage). It is
never committed to this repo, and nothing in this project fetches or scrapes those sites. Whoever imports a file is
responsible for following its source's terms, which for Prydwen means personal, non-commercial use and no automated
scraping.
